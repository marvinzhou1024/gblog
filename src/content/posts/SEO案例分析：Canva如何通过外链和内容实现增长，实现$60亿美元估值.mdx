利用搜索意图激发落地页
Canva为大多数用例提供了两个关键的落地页：
一个用于发现，一个用于创建。
看看下面的例子。左边是一个为想要设计证书的人提供的页面，右边是一个为寻找证书模板的人提供的落地页。这两种搜索者都在寻找像Canva这样的解决方案，但他们看待问题的方式不同。
![](https://img.aimashen.com/mashen/2025/04/889cc8794ed6319e82110e98d81270f4.png)
左边的落地页针对“设计证书”和“创建证书”等关键词排名，每月获得16,000次访问。右边的落地页针对“证书模板”和“免费证书模板”等关键词排名，每月产生33,000次点击。这两个落地页在Canva的SEO策略中都扮演着重要角色，我们将在本文中深入探讨。
但核心在于，Canva在这些落地页上的成功归结为几个基本理念：
- 理解使用Google的人的意图
- 为其他落地页建立父子关系
- 创建可扩展的落地页结构
- 投资于反向链接外链
- 创建强大的内容文化
理解使用Google的人的意图
搜索意图是SEO的基本组成部分，但营销人员和内容创作者常常忽视它。大多数SEO只关注关键词量，而他们应该思考这些关键词背后的意图。搜索意图是当人们在搜索引擎中输入查询时的目标。
在线搜索意图有四种主要类型：
- 信息型：寻找信息（例如，“Prince是谁？”）
- 导航型：想要到达某个特定地方（例如，“Canva博客”）
- 交易型：寻找购买、使用或下载的资源（例如，“创建邀请函”）
- 调查型：试图比较资源（例如，“Canva vs. Adobe Spark”）
让我们重新审视Canva的那两个落地页。两者都迎合了交易型意图，但一个落地页吸引那些想要做某事的人（“创建证书”），而另一个吸引那些想要发现某事的人（“免费证书模板”）。
使用Canva的网站架构术语，我们将这两种类型称为“创建页面”和“模板页面”。
创建页面： 用例——证书

主要关键词： 证书制作工具，创建证书，制作自己的证书
流量： 16,000 / 月

落地页和目录：针对小众意图和用例的策略
Canva完美运用的一个策略是使用针对不同用例和长尾关键词的内容目录。用于做（创建）和发现（模板）页面的网站架构非常精美：
![](https://img.aimashen.com/mashen/2025/04/f792c4f5706f93c7b286becd89b8be1d.png)v
例如，在做（创建）页面中，“邀请函”的URL将是：
- Canva.com / templates / search / invitations / save-the-date
/ invitations 是资源，/ save-the-date 是小众资源
对于发现（模板）页面中的邀请函，URL将是：
Canva.com / Create / Invitations
该URL将有一个链接，指向各种邀请函模板，例如：
- Canva.com / templates / search / invitations / save-the-date
- Canva.com / templates / search / invitations / christmas
- Canva.com / templates / search / invitations / wedding
- Canva.com / templates / search / invitations / baby-shower
在整个网站中，我们发现Canva有超过55个父页面，每个父页面最多有78个子页面。例如，以下是“邀请函”落地页的父子关系，以及构成子落地页（即小众类型的邀请函）的各种关键词变体：
![](https://img.aimashen.com/mashen/2025/04/64ab037f1e7bf0f5937059c6a5a5dcca.png)
这甚至还不是邀请函的所有子页面。总共有73个！
但这些子页面中的每一个都能够捕获相当多的反向链接，从而产生大量的流量。仅“邀请函”类别就有900个反向链接，每月通过父页面和子页面产生超过65,000次有机访问。
为什么反向链接重要：反向链接对SEO很有价值，因为它们充当了一个网站对另一个网站的信任投票。搜索引擎通过跟踪反向链接来确定你内容的可信度——你的页面从其他受信任页面获得的链接越多，该页面在搜索引擎中的表现就越好。所有资源指标都可以通过反向链接管理工具进行分析和监控，该工具将显示域名的权威性、链接类型（dofollow或nofollow）、网站流量等。

![](https://img.aimashen.com/mashen/2025/04/f7aebb1dd02856976578688ddb5e08af.png)
这些子页面有来自The Next Web、Yahoo、Thrillist、The Spruce等的链接。这些网站的域名权威性在80到92之间——这意味着它们受到搜索引擎的信任，不太可能充满垃圾信息。事实上，一些与Canva直接竞争相关关键词的网站链接到Canva的子页面，进一步增加了可信度。
与许多这些链接相关的锚文本是“来自Canva的免费[子页面]邀请函模板”。这对于SEO来说再好不过了。每个带有此锚文本的反向链接都告诉Google，该资源是创建电影之夜邀请函、16岁生日邀请函或婴儿派对邀请函的最佳模板。
现在，将这种方法应用于57个父页面（优惠券、信头、发票、传单、标签、书籍封面、课程表等）和300多个子页面，这些子页面本质上是其父页面的小众版本。

例如，估计每月搜索“创建按摩礼品证书”的次数不到15次。但Canva有一个专门针对该关键词的落地页。得益于他们现有的反向链接实力和他们在“证书”领域的权威性，他们能够通过一个长期排名的落地页捕获这种小规模的需求。

投资于个性化的反向链接外链
获得反向链接并非一蹴而就。
如果你希望它在有机流量中产生回报，这是一个需要长期投资的过程。Canva创建的用于排名“信息图表制作工具”或“证书模板”等交易型查询的落地页并非偶然获得所有这些反向链接。Canva有意投资于这些页面，以从第三方（如博主和记者）那里捕获反向链接。
Canva已经组建了一支外链专家团队，他们识别出提到“邀请函”、“海报”或“数字营销工具”等内容，然后联系创作者。

Canva在这次外链中做对了以下几点（在COVID-19期间）：
1. 以同理心的信息开头

Canva是如何做到的？
最重要的部分是投资于强大的内容文化。而强大的内容文化需要一个强大的团队。
内容营销团队需要由优秀的领导者/经理、开发人员、专家（外链）和创作者（作家和优化师）组成。
Canva在人员配备和构建优先考虑SEO的营销引擎方面投入了大量资金。如今，超过75人被列为在Canva工作（兼职或全职），他们的头衔或职位描述中包含SEO。特别是，品牌爆炸性反向链接努力背后的个人被称为“SEO专家”，他们遍布全球，团队成员分布在菲律宾、印度尼西亚、爱沙尼亚、伦敦、基辅、澳大利亚等地。
我们发现了Canva最近发布的一个SEO外链专家的职位招聘：
![](https://img.aimashen.com/mashen/2025/04/5038cf6519a3e0b41b27f88864679939.png)
该职位的职位描述包括：
- 通过我们的外链流程识别高质量博客和网站
- 分析竞争对手并发现新的链接机会
- 保持链接多样性
- 达到每月最低目标
- 向团队发送每周和每月报告

在这个职位列表中，有两点值得注意：
1. 他们提到了一个已经建立的外链流程
2. 他们的SEO专家被赋予了配额就像销售人员一样
根据这个描述，似乎SEO专家负责端到端的链接建设，从发现机会到关闭这些机会并报告。最低配额可能是每月链接量，并且很可能伴随着链接质量的标准。我听说在一些组织中，外链专业人员还会因为超过每月链接配额或成为团队中累计域名权威性最高的表现者而获得奖金。
虽然Canva的SEO团队很可能自2016年以来已经更换了工具，但最初的营销堆栈包括SEMrush、Ahrefs、Mixpanel、Heap Analytics、Google Analytics、Mention和BuzzSumo（根据Inbound.org上的AMA）。
响应新需求创建落地页
全球远程工作的兴起导致Zoom的采用率大幅增加。
视频会议软件是COVID-19初期最受欢迎的SaaS行业之一。乍一看，Canva似乎不会从远程工作和远程办公的兴起中获益太多——但他们确实受益了。对Zoom的需求增加导致对自定义Zoom背景的需求增加。
看看这个Google趋势跟踪“Zoom背景”查询：
![](https://img.aimashen.com/mashen/2025/04/ba9f2e1626ea64b8353e6e82c1a6d8b3.png)
当需求激增时，Canva做出了反应。
他们开发了一个专门用于Zoom背景的新垂直领域。“可定制的Zoom背景”落地页有351个反向链接（60%为“Do Follow”），来自154个域名。在三月底，这个落地页还不存在。自推出以来，它平均每周获得15个新的反向链接。在同一Zoom背景类别中，“创建Zoom背景”落地页有298个反向链接，来自132个域名。
这些资产在三月底之前还不存在。
然而，它们已经开始在排名中上升……
为什么？
第一步是尽可能多地制造话题。他们在Product Hunt上发布了该功能：
如果你不熟悉Product Hunt，它是一个人们分享他们最喜欢的产品，其他人讨论并为他们认为好的产品投票的网站。Zoom背景制作器在Product Hunt上获得了超过300票，但宣传该资产的预告视频目前拥有令人印象深刻的29,362次观看和154个赞。在发布的前七天，Zoom视频的观看量达到了13,000+次：
![](https://img.aimashen.com/mashen/2025/04/2a133cb23fe10a82a26a44f8089f3dc9.png)
这就是你发布新功能的方式。
在过去30天里，该资产已经产生了超过150个引用域名。
![](https://img.aimashen.com/mashen/2025/04/620043e2333cd36bb9c27f2751178a4a.png)
它被AmericanExpress.com、Today.com、The Sun、Gizmodo、Salesforce.org等网站推荐和链接。这并非偶然。
这是因为Canva联系了谈论“2020年如何在家工作”等话题的出版物，并能够获得带有理想锚文本的适当资产的链接。
利用博客内容推动更多成果
在Product Hunt上发布Zoom背景资产后，Canva并没有停止推广新功能。
历史上，该品牌通过他们的博客产生了大量的流量。2015年，Canva的前增长负责人撰写了关于帮助他们60天内将博客流量增加226.47%的技术：
1. 更长的帖子
2. 灵感帖子，如“50张最佳名片”
3. 多样化的内容类型——列表、专题文章、采访等
4. 免费资源
5. 主动的列表构建
以下是实施该策略后他们的增长截图：
![](https://img.aimashen.com/mashen/2025/04/555646ca2dc594f026b48e919c917854.png)
该策略的基本原理至今仍在使用。
Canva认识到他们的博客不仅是流量的载体，还是教育资源和潜在客户生成工具。团队开发了两篇博客文章，针对高搜索量的术语，进一步推广他们的新功能，同时采用了自2015年以来一直有效的公式。
这些文章的标题是：
- 如何使用Zoom虚拟背景（1,790字）
- 让你捧腹大笑的有趣Zoom背景（1,051字）
这两篇博客文章不仅在战略上开发以排名，还旨在转化。在操作指南文章中，“Zoom虚拟背景”一词在标题、H1、H2和正文内容中出现了15次。在灵感文章中，“Zoom背景”一词在标题、元描述、H1和H2中出现了7次。
![](https://img.aimashen.com/mashen/2025/04/687485a5634630d457dea9cbf9c6a00d.png)
博客文章链接回原始落地页，带有完美的锚文本：**Zoom虚拟背景。**但最有趣的是这两篇博客文章生成的新反向链接。仅仅30天内，这些博客文章就有58个链接，并在目标关键词的SERP中上升。
错失的机会：比较页面（调查意图）
现在……尽管Canva做对了很多事情，但有一个领域他们错过了。他们在创建内容以满足每种搜索意图方面做得很好——除了一个：他们没有内容来捕获当某人进行对比搜索时的流量。
以搜索“Canva vs. Adobe Spark”为例。这个短语每月有超过450次搜索，可以安全地假设这些搜索来自那些在两者之间做出决定的人：
![](https://img.aimashen.com/mashen/2025/04/ecfa620851c2c5da89979aa0dbd785eb.png)
排名前三的文章并非来自Adobe Spark 或 Canva。创建一个针对这些关键词的落地页将使任何一个品牌在有人登陆这个SERP寻找答案时掌握叙事权。我的预期是，如果这两个品牌都没有利用这个搜索量，各种在线评论网站最终会开始崭露头角，引领B2B的Yelp化。
Google自动完成建议澄清了这里的机会：
![](https://img.aimashen.com/mashen/2025/04/f62a9477ae95e3972b0cabb227791b3a.png)
比较落地页可以成为与漏斗底部的人联系并捕获再营销潜在客户的好方法。在购买过程的这个阶段，某人通常在你和你的竞争对手之间做出决定。开发一个可以影响该个人倾向于你品牌的资产是捕获价值的明智方式。
总结
任何营销人员都不可能读完这篇文章并在48小时内解锁与Canva类似的结果。建立一个反向链接帝国并创建一系列可持续的落地页需要时间，这些页面在开发后长期为你工作。编写职位描述、创建培训、制定薪酬模型并组建一组外链专家和专家需要时间。Canva所取得的成就令人印象深刻。
虽然任何品牌要复制他们的成功肯定不会容易，但肯定可以以Canva为灵感继续前进。最好的组织会认识到，这一切都归结为创建一种文化，这种文化理解并真正相信内容是推动成功的关键因素。
